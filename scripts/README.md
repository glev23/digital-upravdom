# scripts

Служебные скрипты: старт контейнера, единая проверка, наполнение данными,
ручные прогоны и замеры. Всё, что не нужно в рантайме, вызывается вручную.

## Запускаются автоматически

| Скрипт | Назначение |
|---|---|
| `entrypoint.sh` | Старт контейнера `app`: миграции → справочники → демо-данные → векторы БЗ → приложение |
| `seed_problem_types.py` | Справочник типов проблем (11 кодов, сроки из ПП №354) |
| `seed_demo.py` | Демо-состояние: УК, РСО, дома, deep-link токены, уведомления; идемпотентно |
| `load_kb.py` | Загрузка предпосчитанных векторов `data/kb/` в Qdrant |

## Проверка проекта

| Скрипт | Назначение |
|---|---|
| `check.sh` | Единая проверка: ruff, mypy (strict), pytest, `docker compose config`, поиск секретов |

```bash
bash scripts/check.sh
```

## База знаний

| Скрипт | Назначение |
|---|---|
| `build_kb.py` | Пересборка `data/kb/` из `data/kb/sources/*.md` (чанкинг + эмбеддинги) |
| `kb_smoke.py` | Контрольные запросы к базе знаний: попадание нормы в top-5 |
| `reindex.py` | Пересоздание коллекции Qdrant из артефактов |
| `export_onnx.py` | Экспорт модели эмбеддингов в ONNX (используется в сборке образа) |

## Ручные прогоны на живой модели

Нужны поднятые Postgres и Qdrant и `OPENROUTER_API_KEY` в `.env`. Тратят
суточный лимит бесплатной модели — запускать точечно, не циклом.

| Скрипт | Назначение |
|---|---|
| `classify_demo.py` | Классификация 15 сочинённых фраз: ветки auto / уточнение / «не уверен» |
| `rights_demo.py` | Справка по нормативам; `--uk <ключ или uuid>` подмешивает документы конкретной УК |
| `llm_smoke.py` | Проверка доступности модели и формата ответа |
| `model_bakeoff.py` | Сравнение моделей на реальном промпте: доля основания, auto, стабильность на повторах, задержка |

## Замеры метрик

| Скрипт | Назначение |
|---|---|
| `run_accuracy_check.py` | Точность по двум осям против двух baseline и режима без LLM (`data/test_cases/`) |
| `run_dedup_check.py` | Доля верных склеек и ложных склеек на группах описаний одной аварии |
| `spike_embeddings.py` | Замер рантайма эмбеддингов (SPIKE-001) |

## Действия диспетчера (демонстрация)

| Скрипт | Назначение |
|---|---|
| `ticket_status.py` | Смена статуса заявки с уведомлением подписчиков |
| `ticket_reroute.py` | Переадресация заявки другой организации |
| `notify.py` | Уведомления об отключениях: `list`, `create`, `close` |

```bash
docker compose exec app python scripts/notify.py list
```
